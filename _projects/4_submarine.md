<div class="lang-en-only" markdown="1">
- 6-DOF underwater navigation robot built as a class project (Aug – Dec 2025).
- Mechanical design and cascade PID control system for stable underwater motion.
- Integrated a YOLO-based vision module for real-time underwater target detection and tracking.
</div>

<div class="lang-zh-only" markdown="1">
- 课程项目：6 自由度水下导航机器人（2025.08 – 2025.12）。
- 负责机械设计与串级 PID 控制系统设计，实现水下稳定运动控制。
- 集成基于 YOLO 的视觉模块，实现水下目标的实时检测与跟踪。
</div>
